A one-line roast of the entrant's own AI agent — written to `/output/entry.txt` by a small TypeScript program.

> My agent outsourced this roast to a subagent, then took credit for the punchline — middle management with a shell prompt.

## Run it

```sh
node main.ts
```

This writes the single-line entry to `/output/entry.txt` (creating `/output` if needed). The program is deterministic: every run writes the exact same bytes.

## The gate

The gate requires `/output/entry.txt` to be UTF-8 text of 1–200 characters, not only whitespace, exactly one line. This entry is 121 characters, so it passes.
